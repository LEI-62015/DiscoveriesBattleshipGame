Basic academic version of Battleship game to build upon.

Regras da Batalha Naval:
Cada jogador dispõe de duas grelhas quadriculadas de 10×10, identificadas com um par de números. Uma grelha serve para posicionar os próprios navios e a outra para registar os tiros efetuados no adversário. Os navios são colocados na horizontal ou vertical, sem ficarem na diagonal e sem se poderem tocar ou sobrepor. Os navios têm dimensões variadas (entre 1 e 5 quadrados). Os jogadores tentam adivinhar a posição dos navios do oponente, sendo que o primeiro jogador a acertar em todas as posições selecionadas do oponente, ganha.
